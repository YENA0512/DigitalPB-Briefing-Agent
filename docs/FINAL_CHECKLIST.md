### 3번에 쓸 코드 — 두 개를 추천한다

**① `src/reducers.py` 의 `keep_latest_round`** — 이게 이 프로젝트에서 가장
설명 가치가 높다. "fan-in 때문에 reducer 가 필요한데, `operator.add` 로는
그 칸을 비울 수 없어서 Feedback Loop 이 성립하지 않았다"는 이야기는
**LangGraph 를 실제로 써본 사람만 할 수 있는 이야기**다. 강사A 가 평가한다.

**② `src/sources.py` 의 `render()`** — 내부 심사용 태그와 대고객 표기를
분리하는 지점. 규제 산업에서 "기계가 대조할 라벨"과 "고객이 읽을 표기"가
다르다는 설계 판단을 보여준다.

### 5번에 쓸 어려움 — 실제로 겪은 것 4가지

1. **Feedback Loop 이 구조적으로 복구 불가능했다** — `operator.add` reducer.
   문구는 멀쩡한데 1회차 실패 기록이 남아 영원히 반려. `keep_latest_round` 로 해결
2. **글자수 제약을 풀었더니 비용이 내려갔다** — 74자로는 "변동+기여+원인"이
   안 들어가 LLM 이 계속 반려됐다. 220자로 올린 뒤 **호출 23→15회, 폴백 0**
3. **FMP 무료 등급으로는 코스피·환율·반도체가 전부 막혔다** — Yahoo Finance 로 교체
4. **과편중 고객에게 과보수 콘텐츠가 추천됐다** — 두 글이 같은 태그를 달고 있어서.
   진단 상충 감점으로 해결

### ✅ MCP 적용 완료 (2026-10-12)

`mcp_servers/market_server.py` — `FastMCP` + `streamable-http`, 도구 6종.
교육과정 `w4_nb04`(로컬 MCP 서버 만들기)·`w5_nb01b_rag_mcp`(RAG 를 MCP 로
내보내기)와 같은 방식이고, 클라이언트는 `MultiServerMCPClient` 다.

발표에서 할 말 — *"시황·뉴스 Tool 을 MCP 서버로 분리했습니다. 투자홈 브리핑,
PB 상담 봇, 리포트 요약기가 **같은 시세 정의**를 쓰게 됩니다. 단기 전망
임계값이 팀마다 달라지는 사고를 막습니다."* **현업 확장 가능성**(강사B 의
평가 축)에 바로 닿는 이야기다.

**고객 데이터는 서버로 넘기지 않는다** — `news_for_holdings` 는 종목명만 받고
보유 금액·비중은 Agent 쪽에 남는다. 규제 산업에서 Tool 을 외부로 뺄 때
무엇을 경계로 삼았는지 설명할 거리가 된다.

**MCP 가 죽어도 데모는 돈다** — 서버가 없으면 직접 호출로 떨어지고 로그에
`(직접 · Yahoo Finance)` 로 찍힌다. 발표장 리스크를 없앤 설계이고 이것 자체가
설명거리다.

### 남은 것 — n8n

D-5 에 n8n 까지는 무리다. 발표에서 *"배치 스케줄링은 n8n 으로 뺄 수 있습니다"*

## 5. 데모 — 무엇을 어떻게 보여줄 것인가

교재 p18: *"**실제 입력을 넣고 Agent 가 실행되는 화면**(필수)"*

그래서 산출물을 두 개로 나눴다.

| | `app/briefing_app.py` (Streamlit) | `demo/viewer.html` |
|---|---|---|
역할 | **주력 데모** | 백업 |
Agent 실행 | 🟢 실제로 돌고 노드 로그가 스트리밍됨 | ❌ 완성된 JSON 재생 |
AS-IS 비교 | ❌ | 🟢 카드 4종 랜덤 재현 |
환경 의존 | Python + 포트 | 브라우저만 |

**발표 순서 (1분 30초)**

1. `지금 생성 (Batch)` 모드로 실행 → 노드 로그가 흐르고 3축 심사 결과가 뜬다
   → *"전날 밤에 일어나는 일입니다"*
2. 오른쪽 모바일 화면이 채워진다 → 출처 ①② 를 보여준다
3. 질문 칩 **"내 자산 구성 괜찮아?"** 클릭 → 점검 포인트 노출
   → *"고객이 자유 입력을 하는 게 아니라, 미리 승인된 질문만 누릅니다"*
4. `승인본 재생 (Runtime)` 으로 전환 → **LLM 호출 0회**
   → *"고객 진입 시점에는 모델을 부르지 않습니다. 금소법 때문입니다"*
5. (시간 남으면) `demo/viewer.html` 로 AS-IS 랜덤 추첨 보여주기

**반드시 녹화해 둘 것.** 교재가 "라이브 또는 녹화영상"을 허용한다.
네트워크·포트·API 키 중 하나만 어긋나도 라이브는 날아간다.
