# 데모 녹화 대본 — 최종발표용

교재 p18: *"데모 시연 — 라이브 실행 또는 **녹화영상**. 화면 없으면 감점"*

**녹화를 권합니다.** 네트워크·포트·API 키 중 하나만 어긋나면 라이브는 날아갑니다.
녹화본을 틀고, 질문이 나오면 그때 라이브로 보여주는 것이 안전합니다.

---

## 0. 녹화 전 준비 (5분)

```bash
cd "~/My project/AI ELITE"

# ① MCP 서버 — 로그에 (MCP · Yahoo Finance) 로 찍혀야 한다
./run_local.sh mcp &

# ② 앱
./run_local.sh app          # http://localhost:8501

# ③ 승인본이 비어 있으면 채운다
./run_local.sh batch -- --auto-approve --limit 5
```

| 확인 | 왜 |
|---|---|
브라우저 **확대 125~150%** | 발표 화면에서 글씨가 작다 |
터미널 폰트 **16pt 이상** | 같은 이유 |
알림·슬랙 끄기 | 녹화에 팝업이 들어간다 |
`.env` 의 `USE_LLM=true` | "지금 생성"이 진짜로 LLM 을 부른다 |
다크모드 여부 | 앱은 `.streamlit/config.toml` 로 라이트 고정. 터미널은 수동 |

macOS 녹화 — **QuickTime Player > 파일 > 새로운 화면 기록**. 창 영역만 선택.

## 1. 화면 데모 (1분 40초) — 주력

### 장면 1 · 문제 (15초)

왼쪽에 `demo/viewer.html` 을 띄워 둔다.

> "지금 투자홈은 **카드 자리 하나에 네 가지를 준비해두고 접속할 때마다
> 그중 하나**가 나옵니다."

**`🎲 카드 다시 추첨`을 두세 번 누른다.** 카드가 바뀌는 걸 보여준다.

> "고객 상황과 무관하게 뽑힙니다. 문구는 41건 고정이고, 고치려면
> 개발 반영까지 **최소 7일**입니다. 오늘 코스피가 3% 내려도 고객이 보는 문장은
> 7일 전에 확정된 겁니다."

### 장면 2 · Agent 실행 (35초)

앱으로 전환. 사이드바 — 케이스 **반도체편중**, 모드 **지금 생성 (Batch)**,
`검수 자동 승인` **체크**, **▶ 실행**.

> "Agent 가 받는 입력은 세 가지입니다 — 보유 자산, 투자성향, 열람 이력."

왼쪽 `IN` 패널을 1초 가리킨다. (케이스를 바꾸면 이 값이 바뀝니다.)

> "전날 밤 배치에서 일어나는 일입니다. 지금 그래프가 실제로 돌고 있습니다."

왼쪽 로그를 가리키며:

> "진단이 끝나면 **검색 다섯 개가 병렬로** 나갑니다. 일간·주간·월간 리포트,
> 실시간 시황, 그리고 보유 종목 관련 뉴스입니다.
> 시황과 뉴스는 **MCP 서버**를 거칩니다 — 로그에 `MCP` 로 찍혀 있습니다."

> "생성된 문구를 **세 축이 동시에 심사**합니다. 컴플라이언스·근거 결속·형식.
> 하나라도 걸리면 재작성하고 최대 3회까지 돕니다."

### 장면 3 · 결과 (25초)

오른쪽 고객 화면.

> "시황 보드에 코스피·S&P500·환율과 **내 자산을 같은 격자**에 놓습니다.
> 시장보다 덜 빠졌는지 한눈에 보입니다."

> "문구는 **왜 줄었는지**를 설명합니다. 금액은 고객이 이미 화면에서 봅니다.
> 브리핑이 더할 수 있는 건 이유입니다."

**① 을 클릭** → 출처 카드가 하이라이트된다.

> "①을 누르면 근거가 펼쳐지고, 누르면 그 리포트나 기사로 이동합니다.
> 내부 출처 코드는 고객에게 보이지 않습니다."

### 장면 4 · 대화 (15초)

질문 칩 **"내 자산 구성 괜찮아?"** → **"관련 뉴스 보여줘"** 연달아 클릭.

> "칩을 누르면 **앞 대화가 접힙니다.** 방금 물은 것이 눈에 들어오게요."

> "고객은 **자유 입력을 하지 않습니다.** 미리 승인된 질문만 누릅니다.
> 무엇을 물을지 모르면 답을 미리 검수할 수 없기 때문입니다."

### 장면 5 · 검수 (20초)

사이드바에서 `검수 자동 승인` **해제** → 모드 **담당자 검수 (HITL)** → **▶ 실행**.

> "`interrupt()` 로 그래프가 여기서 멈춥니다. **승인 전에는 고객에게
> 나가지 않습니다.** 검수 단위는 고객이 아니라 케이스라서,
> 1건을 승인하면 같은 유형 **3,000명**에게 나갑니다."

**반려** 탭 → 사유 입력(예: *"수치 표현을 더 쉽게"*) → 반려.

> "반려하면 사유가 **재작성 지시**가 되고 optimize 로 돌아갑니다.
> 3축 심사를 다시 받고 여기로 옵니다."

화면에 **반려 이력**이 쌓입니다 — 반려된 문구 / 사유 / 재작성된 문구.

> "무엇이 달라졌는지 보입니다. 재작성 기회는 3회이고, 그래도 안 되면
> **41케이스 원본 문구로 폴백**합니다. 현업이 쓴 문장이라 컴플라이언스가
> 보증됩니다. 생성이 실패해도 서비스는 죽지 않습니다."

(시간이 있으면 4번 반려해 **폴백 배너**를 보여주세요.) 마지막에 **승인**.

### 장면 6 · Runtime (10초)

모드 **승인본 재생 (Runtime)** → **▶ 실행**.

> "고객이 실제로 들어올 때는 이 경로입니다. **LLM 호출 0회.**
> 금소법상 투자 문구는 사람 책임 하에 나가야 하니까요.
> 비용도 고객 수에 비례하지 않습니다."

## 2. 터미널 데모 (1분) — 보조

```bash
./run_local.sh record            # 장면당 4초 자동 진행
PAUSE=6 ./run_local.sh record    # 더 천천히
./run_local.sh record --manual   # 엔터로 넘김 (리허설)
```

6장면이 순서대로 돕니다 — reducer 자기검증 · 41케이스 커버리지 ·
MCP 호출 · 회귀 테스트 7종 · 배치 · 생성 결과 비교.

**이 중 ①번(reducer)은 꼭 넣으세요.** 발표 평가에서 "Agent 설계 구체성 35점"에
직접 닿는 장면입니다.

```
operator.add(r0, [])      → 3건. 비워지지 않는다
  이후 전부 통과해도       → all(passed)=False  ← 영원히 반려
keep_latest_round(r0, r1) → rev 1 만 남음 → True
```

> "fan-in 때문에 reducer 가 필요한데, `operator.add` 로는 그 칸을 **비울 수가
> 없습니다.** 재작성해서 문구가 멀쩡해져도 1회차 실패 기록이 남아 영원히
> 반려됐습니다. 회차를 보고 스스로 버리는 reducer 로 바꿨습니다."

## 3. 백업 (라이브가 깨졌을 때)

| 상황 | 대응 |
|---|---|
앱이 안 뜸 | `demo/viewer.html` 더블클릭 — 브라우저만 있으면 된다 |
네트워크 차단 | `USE_LLM=false ./run_local.sh app` — 승인본 재생은 외부 호출 0 |
MCP 서버 없음 | 그냥 진행. 로그가 `(직접 · Yahoo Finance)` 로 바뀔 뿐 |
전부 안 될 때 | 녹화본 재생 |

## 4. 녹화 후 체크

- [ ] 금액·고객정보가 목데이터인지 (실데이터 화면이 섞이지 않았는지)
- [ ] 터미널에 `.env` 내용이나 API 키가 스쳐 지나가지 않았는지
- [ ] 사내 화면 캡처가 들어가지 않았는지
- [ ] 소리 — 알림음이 들어갔으면 음소거하거나 다시 녹화
- [ ] 길이 10분 발표 중 **2분 이내**. 넘으면 장면 2·3만 남긴다
